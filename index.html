📁 dataset/

Data Management

จัดเก็บข้อมูลปฐมภูมิจากกรมควบคุมมลพิษ (Air4Thai) ย้อนหลัง 5.5 ปี (2021–2026) ครอบคลุม 105 สถานี และชุดข้อมูลที่ผ่านการ Imputation เติมค่าสูญหายด้วยเทคนิค Linear Interpolation พร้อมไฟล์ Data Dictionary กำกับความหมายทุก Feature

6 ไฟล์หลัก (.xlsx, .csv) ~840 KB (รองรับ Git LFS)

📁 ml_models/

AI & Benchmarks

สคริปต์สำหรับการทดลองและคัดเลือกโมเดล (Model Selection): Linear Regression, Decision Tree, Random Forest, Gradient Boosting/XGBoost บันทึกค่า Model Weights (.pkl) และสคริปต์คำนวณ Error Metrics (R², MAE, RMSE) บน Test Set

Python 3.10+ / Scikit-Learn / XGBoost Best Model: XGBoost (Peak Acc 62.2%)

📁 web/

Production Frontend

ระบบเว็บแอปพลิเคชัน AirGuard AI สำหรับผู้ใช้งานจริง เชื่อมต่อ Live Open-Meteo Realtime API พยากรณ์อากาศ 7 วันล่วงหน้า ระบบประเมินความเสี่ยงรายบุคคล (Personalized Alert) และแดชบอร์ด Benchmark พร้อมรองรับ Dark/Light Mode

Vanilla JS + Chart.js + CSS Glassmorphism 100% Fully Responsive
